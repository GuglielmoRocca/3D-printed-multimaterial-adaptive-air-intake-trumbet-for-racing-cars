In this project, the feasibility of a variable-geometry intake trumpet manufactured using additive manufacturing techniques was investigated.
Through an actuation mechanism, the intake trumpet can modify its opening depending on the operating conditions; this capability is enabled by the selected material and its geometry.
Furthermore, a CFD analysis was carried out to highlight the performance gains achieved through the geometric variation.
In addition, a techno-economic analysis was conducted.
